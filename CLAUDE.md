# Алхимия Талиса — памятка для Claude

Домашняя система алхимии D&D 5e для персонажа Талиса (чародей, серебряное драконье наследие). Пользователь — игрок Талиса. Писать по-русски; о людях — нейтрально (они/их), пол не угадывать.

## Люди

- Мастер — Никита (в файлах — «мастер»). Цены и правила мастера — его ориентир.
- Юля — игрок Лаэля (эльф, волшебник), сама водит свои игры; к её опыту ведения относиться всерьёз.
- Рифт — ещё один игрок.
- Фаэнон — паладин, союзник; Лаэль и Фаэнон — союзники Талиса.
- **Ник игрока в Telegram в файлы не записывать никогда.**

## Ветка и коммиты

- Перед работой прочитать `AGENTS.md`: общие правила разделения задач, веток и генерации для Claude и Codex.
- Тексты для людей писать и переписывать по `WRITING.md` (структура «Коротко → рекомендации → цифры → метод», русские термины вместо английских, чек-лист).
- Короткий рабочий порядок на будущие задачи — `WRITING_QUICK.md`; вступления сборщиков — `scripts/reading_guides.py`. Справке и короткому указателю не добавлять длинное вступление ради шаблона.
- Claude работает в `claude/alchemy-talis-crash-test-6g8sk7` — общей ветке проекта; Codex работает в `codex/<задача>`. Не отправлять чужую ветку в общую автоматически.
- Если среда выдала другую ветку, проверить статус и основу checkout. При чистом checkout Claude может перейти в общую ветку; незавершённые изменения сохранить и не переносить без выяснения их принадлежности.
- После завершённой проверенной правки Claude — коммит только файлов задачи и обычный `git push -q origin claude/alchemy-talis-crash-test-6g8sk7`. Codex пушит только свою ветку. PR не создавать без отдельной просьбы.
- Готовые ветки Codex объединяет Claude по порядку из `AGENTS.md`, затем пересобирает зависимые документы и проверяет результат.
- Python запускать с `-B`; проверочную генерацию выполнять во временной копии. Удалять только временные файлы, созданные текущей задачей, а не заранее существовавшие пользовательские результаты.

## Правила работы

- **Статусы решений:** «утверждено мастером», «решение игрока», «предложение». Новые правила — только с согласия игрока; записывать в «Журнал решений.md» (сейчас до Ж-129).
- **Цены не трогать** — это ориентир мастера.
- **Реестр не раздувать** без просьбы; вторую волну кандидатов в реестр не трогать.
- **«Карточки эликсиров»** идут мастеру — туда только то, что можно мастеру, без материалов только для игрока.
- **Знание игрока ≠ знание персонажа:** Талис не знает, что сова — Аэлиус и что Аэлиус — дракон Аэлитриакс.
- На просьбу «актуальные версии» — прислать файлы (SendUserFile). На «файлы, которые менялись» — список из `git diff --name-only` от прошлой отправки.
- Внешние проверки (аудиты): каждое утверждение сверить с файлами; ошибки текста и кода исправлять; вопросы баланса и новые правила — нести игроку с вариантом и рекомендацией. Не переоткрывать уже решённое (журнал).

## Сборка

- Весь комплект без записи в checkout: `python3 -B scripts/check_all.py` (`--slow` — также экономика, `--browser` — Playwright; Chromium по умолчанию `/opt/pw-browsers/chromium`, другой путь через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`).

- Правила (полные + за столом): `python3 scripts/rules_html.py`
- Любой md → html (для мастера, экономика, ядро и т. п.): `python3 scripts/master_html.py "Имя файла без .md"`
- Карточки: `python3 scripts/cards/gen.py && python3 scripts/cards/gen_html.py && python3 scripts/cards/check.py` (должно быть 0 ошибок); бонусы: `python3 scripts/cards/quality.py`
- Экономика: `python3 scripts/report.py` (долго, Монте-Карло), затем html через master_html.py
- Помощник: `python3 scripts/cards/helper.py`, затем опубликовать: Artifact, `file_path` = «Помощник варки.html», `url` = https://claude.ai/artifact/9ahrBRLCbGqR7y5myPKor2 (общая база: коллекции `tracks` и `belt/state`)
- Пульт мастера: `python3 scripts/cards/master_panel.py` (берёт «коротко на утверждение», ядро, карточки, лист, образец), затем Artifact, `file_path` = «Пульт мастера.html», `url` = https://claude.ai/artifact/F5chdTVmCghTWf2wuYSzu4. Ответы мастера читать: ArtifactData list `answers`.
- Обзор каталога: `python3 scripts/elixir_catalog_review.py --write`; книга игрока и архивы: `python3 scripts/player_book.py` (во временной копии), проверка — `node scripts/test_player_book.cjs`. Книга включает журнал решений, правила, лист и др. — пересобирать после их правки.
- Тесты расчётов: `python3 -B scripts/test_economy.py`, `python3 -B scripts/test_party_kit.py`.
- Проверка помощника — Playwright с `executablePath: '/opt/pw-browsers/chromium'`.
