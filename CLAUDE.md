# Алхимия Талиса — предметная памятка проекта

Домашняя система алхимии D&D 5e для персонажа Талиса (чародей, серебряное драконье наследие). Пользователь — игрок Талиса. Писать по-русски; о людях — нейтрально (они/их), пол не угадывать.

## Люди

- Мастер — Никита (в файлах — «мастер»). Цены и правила мастера — его ориентир.
- Юля — игрок Лаэля (эльф, волшебник), сама водит свои игры; к её опыту ведения относиться всерьёз.
- Рифт — ещё один игрок.
- Фаэнон — паладин, союзник; Лаэль и Фаэнон — союзники Талиса.
- **Ник игрока в Telegram в файлы не записывать никогда.**

## Ведение проекта

- С 01.11.2026 проект целиком ведёт Codex по поручению игрока. Порядок работы, проверок и самостоятельного объединения в основную ветку — в `AGENTS.md`; текущее состояние — в `Состояние проекта.md`.
- Файл называется `CLAUDE.md` для совместимости; ждать передачи работы Claude не требуется. Основная ветка сохраняет имя `claude/alchemy-talis-crash-test-6g8sk7`.
- Тексты для людей писать по `WRITING.md`, краткий рабочий порядок — `WRITING_QUICK.md`. Вступления сборщиков — `scripts/reading_guides.py`.
- Генерация — в свежей временной копии без `.git`, Python — с `-B`. Готовые документы и проверенные исходники включать в основную ветку по завершении задачи.
- JSON сохранения, исходные данные HTML и опубликованный помощник различать. Доступ к репозиторию сам по себе не даёт доступа к аккаунту игрока, браузерному сохранению или базе Claude Artifacts.

**Единицы Талиса (Ж-145):** мастер разрешил использовать 2 единицы от черты как общий пул, включая Волшебное указание и создание ячеек. Максимум 7 (5+2), текущий остаток 6 (4+2). Ограничение «только на метамагию» к Талису не применять.

## Правила работы

- Дополнения игрока, найденные при пересмотре записей игры, встраивать в хронологию соответствующей сцены в логах, а не собирать отдельным блоком в конце. В присланных репликах исправлять орфографию, грамматику и пунктуацию, сохраняя смысл и разговорную манеру персонажей.
- При расширении логов сохранять явные ремарки игрока о чувствах, мыслях, интонации, степени реакции и попытках её скрыть. Реплика не заменяет такую ремарку. Уплотнение абзацев и вынос боя не должны убирать эти пояснения; при уточнении фактов менять только затронутые факты.
- **Статусы решений:** «утверждено мастером», «решение игрока», «предложение». Новые правила — только с согласия игрока; записывать в «Журнал решений.md» (сейчас до Ж-150): там одна строка на решение, полный текст — в `Архив/Журнал решений — полный текст.md` (обновлять оба).
- **Цены не трогать** — это ориентир мастера.
- **Реестр не раздувать** без просьбы; вторую волну кандидатов в реестр не трогать.
- **«Карточки эликсиров»** идут мастеру — туда только то, что можно мастеру, без материалов только для игрока.
- **Знание игрока ≠ знание персонажа:** Талис не знает, что сова — Аэлиус и что Аэлиус — дракон Аэлитриакс.
- На просьбу «актуальные версии» — выдать доступные ссылки на проверенные файлы. На «файлы, которые менялись» — список из `git diff --name-only` от прошлой отправки.
- Внешние проверки (аудиты): каждое утверждение сверить с файлами; ошибки текста и кода исправлять; вопросы баланса и новые правила — нести игроку с вариантом и рекомендацией. Не переоткрывать уже решённое (журнал).

**Подготовка алхимии (уточнения игрока 10.11.2026):** чернила Лаэлю Талис делает по своей инициативе за свой счёт; не предлагать его аванс, финансирование или компенсацию. Интерес к эликсирам должен возникать в игре: каталог не даёт персонажу знания рецептов и готовых мотивов. Возможный разговор с Анариэль о том, как она совмещает магазин и производство, — зацепка к Бдительному отдыху, ещё не событие. Новые мотивы и зацепки обозначать предложениями.

**Редактура по просьбе игрока 10.11.2026:** убрать из текущих книг и планов повторные напоминания об освоенных чернилах, прежних 30/100 и ненужности повторного исследования. Не возвращать эти предупреждения при следующих правках. Статусы хранить в учёте, инструкции писать о текущем действии.

**Практическая раскладка по просьбе игрока 10.11.2026:** показывать расход материалов без экономии на объявленное число попыток, запас на повторы, конкретные границы к20 и экономию при выбранном бонусе, диапазон часов. Различать запас на попытки и время до успешного результата; дополнительный ущерб осечек отдельно. Для лаборатории показывать границы после ремонта +7 рядом с рабочим местом +5.

**Вероятная очередь игрока, 10.11.2026:** чернила → рецепт 2.2 → зелья лечения. В этом маршруте после двух обычных наборов и открытия рецепта старт варки 6/15, нужно девять практик. Не добавлять до варки Разум и Бдительный отдых ради стартовых 8/15. Четыре партии — 8 часов, запасная пятая — 10 часов суммарно; выполнение ещё не состоялось.

## Сборка

- Весь комплект без записи в checkout: `python3 -B scripts/check_all.py` (`--slow` — также экономика, `--browser` — Playwright; Chromium по умолчанию `/opt/pw-browsers/chromium`, другой путь через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`).
- **Какую проверку когда (Ж-131).** Правка текста (`.md` вне `scripts/`): `check_all.py --quick`, около 25 с; браузер и три долгих сборщика пропускаются, пока не менялись код, шаблоны, HTML, JSON и их отчёты, иначе режим сам становится полным. Правка кода, шаблонов или HTML: `check_all.py --browser`, около 100 с, браузерные тесты идут параллельно (`--jobs`). `--slow` (ещё 45 с) — только при правке расчётов экономики. Время каждого шага печатается.
- Публиковать помощник и пульт, пересобирать книгу и zip — только если их собранный файл изменился; пакет ревьюера — только по просьбе. Журнал читать коротким; полный текст и логи сессий — поиском по номеру Ж- или ключевому слову, а не целиком.

- Правила (полные + за столом): `python3 scripts/rules_html.py`
- Любой md → html (для мастера, экономика, ядро и т. п.): `python3 scripts/master_html.py "Имя файла без .md"`
- Карточки: `python3 scripts/cards/gen.py && python3 scripts/cards/gen_html.py && python3 scripts/cards/check.py` (должно быть 0 ошибок); бонусы: `python3 scripts/cards/quality.py`
- Экономика: `python3 scripts/report.py` (долго, Монте-Карло), затем html через master_html.py
- Помощник: `python3 -B scripts/cards/helper.py`. Выдать игроку готовый HTML; перенос состояния — отдельным JSON. Прежняя публикация: https://claude.ai/artifact/9ahrBRLCbGqR7y5myPKor2 (общая база: `tracks` и `belt/state`). Её обновление требует доступного инструмента; локальная сборка публикацию не меняет.
- Пульт мастера: `python3 -B scripts/cards/master_panel.py` (берёт «коротко на утверждение», ядро, карточки, лист, образец). Прежняя публикация: https://claude.ai/artifact/F5chdTVmCghTWf2wuYSzu4, старые ответы — коллекция `answers`; уточнения 12.11 — отдельная коллекция `answers_followup_20261112`. Читать ответы и обновлять публикацию только через доступный инструмент; при отсутствии доступа запрашивать выгрузку.
- Обзор каталога: `python3 scripts/elixir_catalog_review.py --write`; книга игрока и архивы: `python3 scripts/player_book.py` (во временной копии), проверка — `node scripts/test_player_book.cjs`. Книга включает журнал решений, правила, лист и др. — пересобирать после их правки.
- Тесты расчётов: `python3 -B scripts/test_economy.py`, `python3 -B scripts/test_party_kit.py`.
- Проверка помощника — Playwright с `executablePath: '/opt/pw-browsers/chromium'`.
