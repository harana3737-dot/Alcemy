# Алхимия Талиса: для мастера

06.10.2026. Всё по алхимии Талиса для мастера — в этой папке. Файлы пронумерованы в порядке чтения.

## Что нужно от тебя

**Только файл 1.** Там 42 вопроса, по строке на каждый. Если по пункту молчишь — играем как в столбце «Играем». Достаточно ответить: «всё ок, кроме …». Единственное число, которое нужно назвать, — цена в пункте 19.

Остальные файлы — справочные: открывать, когда хочется проверить, как что работает.

## Как читать номера

- **В-01, В-46** — номер вопроса в очереди; в файле 6 по нему подробности.
- **7.5, 8.6** — раздел правил; искать в файлах 3 и 4.
- **Ж-100** — номер решения в журнале решений (журнал у игрока).
- **«Решение игрока»** — так играем, пока ты не скажешь иначе. **«Утверждено мастером»** — твоё.
