# Шаэрра — отдельная кампания

Игрок подтвердил: Шаэрра — из другой кампании, отдельной от Талиса. Эта папка — самостоятельный комплект её материалов. Для продолжения работы читать [состояние кампании](Состояние%20кампании.md) и [инструкцию](AGENTS.md).

Доступны присланный игроком HTML «Руны Шаэрры» (заголовок внутри — «Тетрадь Шаэрры») и два поступления найденных игроком текстов. Во втором комплекте есть исправленная предыстория, согласованный с HTML файл фраз и дополненная история доработок. Все вложения сохранены без изменений. Актуальность черновиков игрок не помнит; сравнение с HTML — в отдельной сверке. Предыстория теперь найдена, полный лист и логи сессий пока отсутствуют.

## Как устроена тетрадь

Утром выбираются два числа 1–20, по одной руне из двух мешочков. Первая — **Течение**, то, что уже движется; вторая — **Воля**, что с этим можно сделать. Порядок имеет значение. Для всех 400 пар предусмотрено прочтение, особые сочетания и подсказки по использованию камней.

Числа 1–6 относятся к Беде, 7–14 — к Туману, 15–20 — к Прорыву. Холодный край Тумана — 7–8, середина — 9–12, тёплый край — 13–14.

**Знамение.** В тексте приложения записано: заменить бросок атаки, спасбросок или проверку характеристики своим записанным числом; решение до броска, не чаще раза в ход, каждое число один раз. Неистраченные числа сгорают на следующем продолжительном отдыхе. Интерфейс рассчитан на два камня; упоминание трёх костей с 14-го уровня — справка, не подтверждение текущего уровня Шаэрры.

**Серебряные колкости.** Отдельный блок после чужого успешного броска: исходное число врага — Течение, переброс — Воля; приложение берёт меньшее из двух и оформляет это предсказанием в прошедшем времени. В исходном тексте названы реакция, 60 футов и ячейка I круга. Этот блок не тратит утренние камни Знамения.

**Вечер.** Три поля: что ожидалось утром, что случилось на самом деле и почему, что опровергло бы прочтение. Кнопка закрытия дня добавляет запись в историю. Исходные 1 и 20 при первом открытии — пример, а не записанный бросок игрока.

## Сведения о Шаэрре, встроенные в приложение

Внутри `MEMORY` сохранены три сюжетные отсылки:

- Две Хагалаз — утро турнира, на котором Шаэрра прилюдно победила Зелизан: «Две Хагалаз изменили мою судьбу».
- Две Дагаз — бегство из Дома мимо патрулей: «Две Дагаз дали мне новую».
- Альгиз и Вуньо — первое чудо: сёстры поджидали её, чтобы избить, но удара удалось избежать.

Это сведения из присланного инструмента. Три события совпадают с найденными предысторией и концепцией. Их содержание и редакторские швы разобраны в [сверке черновиков](Сверка%20черновиков.md); актуальность биографических деталей остаётся оговорённой игроком. Номер записи в авторской пометке руны и встроенный пример не являются новым событием текущей игры. Принадлежность к отдельной от Талиса кампании подтверждена игроком; её события и игровые ресурсы ведутся здесь.

## Хранение и перенос записей

Приложение хранит день в ключе браузера `shaerra-day`, историю — в `shaerra-log`. Сам HTML не содержит личные записи из браузера и не переносит их между устройствами.

«Скопировать тетрадь» выдаёт текст JSON формата `v:2`. Кнопка «Добавить в тетрадь» импортирует записи истории и пропускает уже имеющиеся. В этой версии она не восстанавливает поле текущего дня из экспорта: его числа и незакрытую запись при переносе нужно проверить отдельно. Поведение исходного файла здесь не менялось.

Тексты и логика встроены в HTML. Шрифты запрашиваются у Google Fonts; при отсутствии сети используются системные замены.
