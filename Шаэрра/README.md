# Шаэрра — тетрадь к игре

Самостоятельная кампания, отдельная от Талиса. Текущий подтверждённый расклад — **Райдо → Наутиз (7 → 2)**. Расход этих камней ещё не передан.

## Открыть и играть

[Скачать / открыть гадалку](Руны%20Шаэрры.html). Это рабочая версия с собственным предсказанием, компактным видом, поиском и редактированием дневника, полным переносом дня.

1. В старой гадалке открой «Резервная копия» и сохрани текст тетради **перед заменой файла**. На новом устройстве старые записи сами не появятся.
2. Открой новый HTML. Внизу, в «Переносе», вставь старый текст или открой JSON. Выбери «Восстановить всю тетрадь и текущий день». Если файл содержит только историю, выбери «Добавить историю» и введи текущие руны вручную.
3. Проверь два числа, подписи камней, незаконченный вечер и свой текст. Старые выгрузки v2 поддерживаются; поля, которых в старом экспорте не было, восстановить из него нельзя.
4. Для игры включи «За столом». Толкования и все 96 строк на полях доступны в раскрываемом блоке. «Моё предсказание» можно менять; кнопка рядом возвращает предложенную фразу.
5. После игры закрой день и скачай JSON. Историю можно найти по руне, имени или тексту и дополнить позднее. «Отменить последний перенос» возвращает снимок до импорта.

Твоё текущее предсказание для копирования:

> Сегодня кто-то пойдёт по дороге, может быть, мы. Без сюрпризов, шаг за шагом. А в конце пути на ком-то сомкнутся цепи.

Новая копия HTML начинается с примера и не перезаписывает день автоматически. Дата внутри игры необязательна; дата и время закрытия записываются отдельно. Использование камней отмечает игрок.

## Источники и сопровождение

Присланные оригиналы — в [первом](Версии/Первый%20комплект/README.md) и [дополненном](Версии/Дополненный%20комплект/README.md) комплектах. Различия описаны ниже, в разделе «Источники и версии». Старый адрес GitHub не установлен; рабочая версия развивается из присланного HTML.

[Состояние кампании](Состояние%20кампании.md) и [инструкция](AGENTS.md) — для продолжения работы. Внешняя публикация и браузер игрока через репозиторий не обновляются.

Сохранения v3 содержат историю и текущий день: руны, текст предсказания, подписи использованных камней, черновики целей, вечер и дату игры. Добавление истории оставляет текущий день; полное восстановление заменяет оба. Новые записи хранят текст предсказания, а не пересобирают его после обновлений. Для старых записей без этого поля при первом чтении используется существующая предложенная фраза: ранее произнесённый авторский вариант из старого формата восстановить нельзя.

Тексты и логика встроены в HTML, внешние шрифты имеют системные замены. Оформление не добавляет правил и не определяет результат броска без модификаторов.


## Источники и версии

Оригиналы двух поступлений сохранены в `Версии/`; даты внутри них не подтверждают актуальность. Рабочая тетрадь определяет нынешнее поведение, а внутренние пометки старых документов об одобрении не заменяют подтверждение игрока.

Во втором HTML скрипты и главный стиль совпадали с первым; отличалась обёртка экспорта. Исправленная предыстория второго комплекта устранила повторное создание наборов, перенесла первое чудо на утро, исправила «сжигая оружие» на «сжимая» и уточнила возможность наследования. Рабочий текст основан на этой версии. Первые замечания о таких швах больше не считать открытыми.

В концепции названы чаты «Концепт Шаэрры и руны» и «Оценка ДНД предыстории», но сам экспорт `conversations.json` не найден: полноту переноса независимо подтвердить нельзя. Предложения и обратные особые пары сохраняют свои статусы; присутствие текста в тетради не делает его новым правилом. Подробные старые сверки доступны в истории Git, отдельные отчёты из рабочего дерева удалены.
