# Шаэрра — решения и открытые вопросы

Рабочая справка по найденным источникам. Пометки о решениях 20–24.10.2026 переданы из дополненного файла предложений; игрок пока не подтвердил актуальность всех старых черновиков. Их применение в текущей гадалке сверено с HTML. Новых правил эта справка не вводит.

## Основа, уже отражённая в тетради

- Раскладка 1–6 / 7–14 / 15–20; первая руна — Течение, вторая — Воля, порядок важен.
- Наутиз без отдельного перевёрнутого прочтения. Перт, Отал и Уруз перевёрнуты; в концепции верх помечен засечкой.
- При использовании числа камень теплеет. Это оформление Знамения.
- Двойные руны — предупреждение, не приказ; обязательной траты и права отменить решение группы нет.
- Колкости оформляются парой «бросок врага → переброс», механика заклинания отделена от образов. Переброс выше первого сам по себе не создаёт нового успеха, берётся меньшее; итог решается с модификаторами за столом.
- 96 строк на полях адаптированы под мир; изречения Фланесса — авторская стилизация. 20 номеров записей рукой Шаэрры условные.

## Открыто

- Тексты обратных особых сочетаний в интерфейсе остаются помеченными как черновики.
- Третья руна «Исход» для 14-го уровня — предложение на будущее, в рабочий ритуал не включена.
- Ответ мастера о колкостях после числа Знамения пока не найден.
- Текущий уровень, полный лист, остатки ресурсов и полные логи требуют отдельных данных игрока.
