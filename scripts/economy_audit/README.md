# Проверка исправленной экономики, 08.10.2026

Исторический аудит: «Проверка экономики — 2026-10-08.md/.html». Итог исправления: «Исправление экономики — 2026-10-08.md/.html». Исходная общая версия: faf9ec0873057878b0a674cf7e830b21379f016d.

- `results.json` — сохранённая проверка исходной модели, включая ошибки. Это история, не текущая прибыль.
- `verification.json` — исправленная модель: независимая проверка риска и четыре контроля по 40 000 катализаторов с интервалами погрешности.
- `../test_economy_audit.py` — 12 обычных регрессий без expectedFailure: пять исходных контрпримеров, границы тайм-аута, крайние кубики, ограниченный переброс и дефицит недельных часов.
- `../economy_audit.py` — генератор проверки. AST-загрузчик берёт реальные функции и таблицы без побочных запусков старых генераторов.
- `../weekly_economy_report.py` — пять таблиц недельного бюджета из sim_plan.py; сохраняет игровые заметки и примеры сессий. Повторная сборка идентична.

Запускать в свежей временной копии без `.git`, с Python `-B`:

```sh
python3 -B -m unittest discover -s scripts -p 'test_economy*.py' -v
python3 -B scripts/economy_audit.py --runs 40000 --seed 20261008 --output /tmp/economy-verification.json
python3 -B scripts/report.py
python3 -B scripts/weekly_economy_report.py --write
python3 -B scripts/master_html.py 'Симуляция экономики зелий'
python3 -B scripts/master_html.py 'Экономика алхимии — для мастера'
python3 -B scripts/master_html.py 'Недельная варка — план и бюджет'
python3 -B scripts/player_book.py
node scripts/test_player_book.cjs
```

`volume_run` выдаёт TimeoutError, если не достигнут нужный прогресс за 200 подходов. Статистика его не превращает в продажу или обычное завершение. `week` возвращает ожидаемый бюджет, `fits_expected_budget`, `shortfall_hours`, `estimate_only`; положительная оценка не гарантирует срок конкретной недели.

Цены и правила сохраняются. Осечки, ремонт, покупка лаборатории и ограничения оборотного капитала не моделируются. Половина цены нестабильного товара применяется после торговой скидки; существующая трактовка 9.9 → 10.10 сохранена как открытое допущение, с сюжетными ограничениями.
