# Аудит экономики, 08.10.2026

Разбор: «Проверка экономики — 2026-10-08.md/.html» в корне проекта. Исходная версия: faf9ec0873057878b0a674cf7e830b21379f016d. Цены и рабочие модели сохранены.

- `results.json`: изоляция ошибки натуральной 1 в пяти вариантах и четыре контроля по 40 000 катализаторов. Контроль Монте-Карло проверяет исходную модель, включая её дефект; независимая формула изменяет только риск катализатора.
- `../test_economy_audit.py`: два успешных теста и пять ожидаемых падений открытых дефектов. Не отключать эти проверки; при исправлении убрать соответствующий `expectedFailure`.
- `../economy_audit.py`: генератор результатов. Для безопасного чтения старых скриптов используется AST-загрузчик из тестового модуля: реальные определения функций и таблиц без побочных запусков генераторов.

Повторять во временной копии без `.git`:

```sh
python3 -B -m unittest discover -s scripts -p 'test_economy*.py' -v
python3 -B scripts/economy_audit.py --runs 40000 --seed 20261008 --output /tmp/economy-audit-results.json
```

Полные экономические документы: `python3 -B scripts/report.py`. Их текущая повторная сборка дала идентичный Markdown. Контрпример `week(2, 2, 2, 2, 12)` получить через `runpy.run_path('scripts/sim_plan.py')` и вызов `week`: fixed=15.831070889894416, free=0, sale=0; это ожидаемые часы, не выполненный недельный заказ.
