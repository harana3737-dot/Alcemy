# Инструменты для игры за столом

Исходники: `helper_tpl.html` (страница), `table_tools.js` (доступная варка и сохранения), `helper.py` (сборка). JavaScript встраивается в готовый HTML: отдельный файл рядом со страницей не нужен.

## Использование

- На вкладке «Варка», в блоке «Что могу сварить», выбрать «Все рецепты» и отметить уже освоенные рецепты или ступени формул. Отметка ступени распространяется на соответствующие варианты и младшие ступени; она не меняет прогресс исследований в журнале. Свободные названия старых записей журнала автоматически не распознаются. При первом запуске известным считается только лечение 1.1, по листу персонажа.
- «Есть материалы на одну попытку» учитывает известность, мастерство, оборудование, травы, эссенции, компоненты и оставшиеся применения катализатора. Просроченные эссенции исключены. Нестабильные эссенции и рискованные применения отмечены предупреждениями. Это наличие материалов, а не гарантия успеха.
- Число доз/попыток задаёт расход сырья без предполагаемых бонусов экономии. Докупка показывает недостающие позиции и справочные цены. Материалы проектов из раздела «Прочее» не используются как свободные травы. Сырьё не списывается, покупки автоматически не проводятся. Перед фактической варкой следует выбрать первую варку нового варианта и остальные условия на существующей панели.
- «Скачать сохранение» сохраняет сумки, деньги, материалы, известные рецепты, активные эффекты, план, часы и все загруженные записи журнала, а также настройки страницы. Перед восстановлением показывается состав файла; подтверждение заменяет состояние. Сначала скачивается резервная копия текущего состояния. В опубликованном помощнике восстановление меняет и общую базу; вне Claude — только этот браузер. Восстанавливать следует при стабильной связи, когда никто другой не редактирует общую базу. При ошибке выполняется попытка отката, а результат показывается пользователю. Записи в облаке не являются единой транзакцией.

- «Блоки для LSS» собирают текст для ручного переноса в лист Long Story Short: прогресс (мастерство и незавершённые записи журнала; из этапов Корневой метки — только текущий), открытые рецепты, «Зелья и расходники» и «На разборку» Талиса, «Ингредиенты» и сумму монет. Ничего не меняют. Куда вставлять — `Талис — карта листа LSS.md`.
- Сборка `helper.py` сверяет материалы `MAT` с блоком «Ингредиенты» и монетами листа персонажа и останавливается при расхождении.

Корневая метка: лёгкий провал теперь добавляет половину итога без округления вниз; это действует и при записи подхода, и в оценке прогресса.

## Сборка и проверка

В временной копии проекта без `.git`:

```sh
python3 -B scripts/cards/helper.py
python3 -B scripts/cards/check.py
python3 -B -m http.server 8770 --bind 127.0.0.1
```

В другом терминале, с доступным пакетом Playwright и системным Chromium:

```sh
ALCEMY_URL=http://127.0.0.1:8770 node scripts/cards/test_table_tools.cjs
```

Проверяются фильтры, дефициты, общая ступень формулы, просроченные эссенции, отсутствие списаний при расчёте, отказ на повреждённых файлах, прогресс 5,5 при итоге 11, скачивание сохранения, восстановление и сохранение после перезагрузки. Тест работает с чистым профилем браузера и локальной копией, без данных опубликованного артефакта.

## Книга игрока: сборка и проверка актуальности

В свежей временной копии проекта без `.git`:

```sh
python3 -B scripts/player_book.py
python3 -B scripts/player_book.py --check
node scripts/test_player_book.cjs
```

Обычная сборка обновляет «Для игрока — книга алхимии.html» и создаёт «Материалы игрока — читаемый комплект.zip» и «Материалы игрока — исходники книги.zip» по запросу. Архивы исключены из Git; HTML хранится в проекте.

Режим `--check` можно запускать прямо в checkout: он копирует необходимые исходники во временную папку без `.git`, пересобирает книгу по её 22 источникам и шаблону и завершается с ненулевым кодом, если HTML в проекте отсутствует или отличается. Оба архива должны собраться и пройти проверку целостности, но с репозиторием не сравниваются. Исходники, HTML и архивы в checkout не изменяются. Для сборки и `--check` хватает стандартной библиотеки Python; браузерной проверке нужны Playwright и Chromium.
