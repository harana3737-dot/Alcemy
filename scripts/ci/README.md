# Проверить исходники и свежую сборку в CI

Codex, 10.10.2026. GitHub Actions запускает проверку на push, pull request и вручную.

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/путь/к/chromium python3 -B scripts/check_all.py --sources --slow --browser
python3 -B scripts/scenario_engine.py --grid --runs 10000
```

Режим `--sources` проверяет Python-тесты, справочные числа документов, признаки карточек и их списки, реестр вопросов, сборку, JavaScript, размер HTML и браузерное поведение. Готовые документы пересобираются только в временной копии. Их отличия от файлов в Git сообщаются для интегратора и не отменяют успешную проверку исходников. Ошибки проверок и изменение исходного checkout по-прежнему завершают команду с ошибкой.

Без `--sources` команда дополнительно требует актуальности всех готовых документов. Этот строгий режим предназначен для проверки итогового комплекта после объединения и пересборки.

Playwright закреплён в `package.json` и `package-lock.json`, устанавливается вне checkout. Скрипты страниц компилируются без исполнения через Node.js; незаменённые маркеры `__RULE_*__` в готовых страницах отклоняются.

`html_budget.json` задаёт пределы свежих сборок: 600 КиБ для помощника и 650 КиБ для пульта мастера. Предел пульта увеличен на 50 КиБ при добавлении двух полных шпаргалок ремёсел союзников: правил, калькуляторов и локального журнала кузни; исходные шпаргалки не дублируются вручную. Проверка печатает размер в байтах. Эти пределы ловят заметный рост вложенных данных; они не измеряют скорость интерфейса. Изменение предела должно сопровождаться объяснением добавленных данных и, при изменении поведения, замером задержки.

Пульт с ремёслами: 624 424 байта (ранее 550 593). Проверка Chromium при ширине 360 и 1280 пикселей, по 10 переключений с ожиданием двух кадров: максимум новых вкладок 37,4 мс; общие вкладки — 40,2 мс против 56,1 мс до добавления. Это замер в облачном браузере, а не на физическом телефоне.
