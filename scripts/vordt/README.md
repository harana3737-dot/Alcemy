# Проверка исходного боя с Вордтом

Срез Claude: `faf9ec0873057878b0a674cf7e830b21379f016d`, seed 1, тактика выбора цели «фронт». Полный разбор: `Проверка боя с Вордтом — 2026-10-08.md` в корне.

`review-results.json` — 15 сценариев, 10 000 боёв на каждую из двух тактик. Повтор:

```sh
python3 -B scripts/vordt_review.py --runs 10000 --output /tmp/vordt-review.json
python3 -B -m unittest discover -s scripts -p 'test_vordt_audit.py' -v
```

`diagnostic-results.json` — четыре опыта по 10 000 боёв на тактику, HP=130, LA=0, LEAP=0, LR=0, APPROACH=1, POTIONS=1. Это диагностические временные копии, не исправленная версия боя:

- `baseline`: исходная логика.
- `quick-only`: ветка `if quick and casts` заменена на `quick -= 1; casts = [casts[0], 0]`. Второй уровневый Шар заменён заговором, вторая ячейка не тратится. Остальные ограничения бонусного действия остаются ошибочными.
- `shield-only`: при применении Щита КД повышен на 5 и выставлен `shield_on`; в начале своего хода КД возвращён, флаг снят, реакция восстановлена. Восстановление реакций в начале хода монстра удалено. Сделано для основной атаки и дополнительной атаки ярости.
- `quick-and-shield`: обе указанные правки.

Изменения Паутины, геометрии и легендарных действий в этих опытах отсутствуют. Вопросы авторских способностей Вордта не решены. Диагностические проценты нельзя выдавать за новые прогнозы победы.

Девять тестов помечены `expectedFailure`, потому что обнаруженные ошибки всё ещё есть в боевой функции. Они проверяют ожидаемое правило и воспроизводимо падают на нынешнем движке. После исправления снять соответствующую метку; неожиданный успех заставит suite потребовать обновления аудита.
