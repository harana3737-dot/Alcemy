# Измерить скорость сборки и поиска

[Итоги и оставшиеся задачи](../../История%20проверок%20—%20оглавление.md) собраны в одной сводке. Старые развёрнутые аудиты доступны в истории Git.

- `measure_implementation.py` сравнивает реальные команды в двух свежих копиях без `.git` и сверяет результаты.
- `benchmark_library.cjs --root ПУТЬ --output ФАЙЛ` измеряет библиотеку с принудительной раскладкой страницы, прогревом и CPU ×4.
- `benchmark_python.py`, `benchmark_report.py`, `benchmark_search.cjs` сохраняют инструменты первых сравнений. Условия и версии источников необходимо сверять перед повтором.
- JSON в этой папке — сырые выборки и контрольные суммы, а не новые утверждения об актуальном быстродействии. Их даты относятся к измеренным версиям.

Тесты оптимизации: `PYTHONPATH=scripts:scripts/cards python3 -B scripts/test_optimization.py`.
