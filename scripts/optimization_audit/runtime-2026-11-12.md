## Симуляция сохраняет поток случайных чисел

`sim_guidance.py` использует специализированный d20 для стандартного
`random.Random`: пять случайных бит, отбрасывание 20–31, прибавление единицы.
Это та же последовательность вызовов `getrandbits`, что у `randint(1, 20)`.
У переданного пользовательского генератора, включая подклассы `Random`,
сохраняется вызов его `randint`. Подмена `randint`, `randrange` или `_randbelow`
у отдельного экземпляра также использует обычный путь.

Полная команда `python3 -B scripts/report.py` запускалась в двух свежих копиях
без `.git`, по три раза, с чередованием порядка. Медиана: **19,42 → 12,37 с**.
Оба экономических Markdown совпали побайтово. Проверка последовательности
30 000 бросков, полного состояния RNG и прежние контрольные сценарии
с катализатором и обязательным перебросом включены в `test_optimization.py`.
Пулы 7/23 из актуальных правил сохранены.

## Поиск готовит подсветку порциями и восстанавливает исходные узлы

Нормализованный текст и текстовые узлы индексируются один раз. Подсветка
и очистка работают порциями с бюджетом 6 мс; новый ввод отменяет предыдущую
работу. Очистка заменяет группу фрагментов исходным текстовым узлом через
один переиспользуемый DOM Range, без обхода и нормализации всего текста.
Совпадения считаются полностью, для выдержек сохраняются только первые три
позиции. Карточки раскрываются после подготовки подсветки.

`content-visibility: auto` позволяет браузеру пропускать раскладку карточек
вне экрана; для печати это отключено. В браузерах без поддержки свойства
остаётся обычная раскладка. Поиск «е/ё», порядок результатов, копирование
исходного Markdown, переходы по меткам и чтение без JavaScript сохранены.

Chromium 151, CPU ×4, 83 материала, два прогревочных и семь измеряемых запусков
на запрос. Время включает принудительную раскладку страницы; подготовка
подсветки включает паузы между порциями, но исключает задержку ввода 150 мс.

| Запрос | Подсветка до → после, мс | Следующий ввод до → после, мс |

| гильдия | 119,8 → 106,7 | 9,9 → 8,9 |

Списки совпадений имеют прежнее количество. Браузерная проверка также
проверяет отмену посреди обработки, смену категории, точное восстановление
исходного HTML, переход к карточке по ссылке, прокрутку до последнего
материала, печать, мобильный экран и резервное копирование в буфер.

Сырые замеры и контрольные суммы: `runtime-results-2026-11-12.json`.

## Воспроизведение

Подготовить две свежие копии проекта вне checkout без `.git`; в новой копии
собрать библиотеку командой `python3 -B scripts/campaign_library.py`.
Измерения экономики можно повторить существующей
`measure_implementation.py --before ПУТЬ --after ПУТЬ --runs 3 --output ФАЙЛ`;
она дополнительно измеряет недельную сборку, бестиарий, книгу и карточки.

```sh
node scripts/optimization_audit/benchmark_library.cjs --root ПУТЬ --output ФАЙЛ
PYTHONPATH=scripts:scripts/cards python3 -B -m unittest discover -s scripts -p test_optimization.py -v
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium python3 -B scripts/check_all.py --browser --slow
```

Полный прогон прошёл за 112 с: 282 Python-теста, сценарии Node/Chromium,
ESLint, пересчёт экономики и сверка всех готовых файлов. Устаревших файлов нет.

Для интерфейса нужна новая страница «Для игрока — логи, записки и предыстория.html».
Импорт JSON не требуется; публикация на внешнем сервисе этой сборкой не обновляется.
