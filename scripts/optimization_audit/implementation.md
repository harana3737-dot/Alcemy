Codex, 08.10.2026. Продолжение [аудита производительности](README.md). Изменены расчётные модули, сборщики карточек и поиск книги. Цены и игровые правила сохранены.

- **Недельный план — примерно в 8,7 раза быстрее:** 3,03 → 0,35 секунды.
- **Полная проверка бестиария — на 14% быстрее:** 2,64 → 2,27 секунды. Изолированный прототип в первом аудите измерял только calculate + render; здесь измерены реальные команды с запуском Python.
- **Числа в материалах сохранены побайтово.** Совпали экономические Markdown и HTML, недельный план, карточки и результаты бестиария. В книге изменился код поиска; её содержание совпало.
- **Пройдены 81 Python-тест и обе браузерные проверки.** Книга и два ZIP пересобраны.

Как читать: ниже — что внедрено, как повторять расчёты и где лежат измерения. Новые исходные замеры — [implementation_results.json](implementation_results.json); прежние измерения прототипов сохранены отдельно в results.json.

## Что изменено

**Экономика.** sim.py, sim_volume.py, sim_player.py, sim_week.py, sim_plan.py и sim_guidance.py теперь импортируют функции обычным способом. Загрузка не запускает Монте-Карло, не пишет документы, не меняет sys.argv и глобальный генератор random. Таблицы создаёт явный build_tables; команды выполняются под main.

report.py строит объёмные таблицы один раз и передаёт их в расчёт игрока. Затем недельная очередь продолжает тот же поток бросков с сохранённого состояния. Так устранены повторные таблицы и сохранена прежняя выборка, включая её конечное состояние. Константы и дешёвые формулы доступны без построения отчёта.

**Недельный план.** per_hour принимает rng, а week — готовую оценку income. weekly_economy_report.py использует Random(20261008), считает доход один раз на мастерство и передаёт одинаковую оценку в бюджеты 12, 22 и 30 часов. Подмены globals больше нет. Команда sim_plan.py тоже вычисляет одну оценку для всех полей строки.

**Постоянные бонусы.** potion_bonus вычисляется один раз до циклов sim_guidance.sim и run_catalyst. Количество дней, расход единиц чародейства, перенос катализатора между днями и последовательность обращений к RNG сохранены.

**Бестиарий.** Кеш ключей attack, advantage, auto_crit и фактического ac ограничен 4096 записями. Кешируется прежний перебор в прежнем порядке; наружу возвращается новый словарь. Изменение словаря результата или КД монстра не портит следующие вызовы. Вариант с 20 весами вместо 400 комбинаций остался только в прототипе: он менял округление опубликованных чисел.

**Карточки.** cards/cards_model.py содержит общие данные, формулы и prepare_cards. Функция копирует сырой каталог, поэтому сборка не меняет cards_data.C и чужие подготовленные карточки. gen, gen_html, check, registry и quality больше не извлекают код через exec и текстовый маркер. Markdown/CSV и HTML создаются отдельными командами; импорт сборщиков ничего не публикует. Потребители используют явные импорты.

**Книга.** Нормализованный текст каждого раздела записывается в поисковый индекс при загрузке страницы. Фильтр и поиск позиции фрагмента используют готовую строку. Сохранены ё/е, регистр, порядок результатов, поиск в закрытых примерах, раскрытие и переход к фрагменту. Индекс хранит дополнительную копию нормализованного текста; ограничение результатов и задержка ввода не добавлены. Проверка внутренних ссылок при сборке использует множество идентификаторов.

## Как пользоваться модулями дальше

Для полного отчёта порядок зависимостей теперь явный:

```python
import sim_volume
import sim_player
import sim_week

volume = sim_volume.build_tables()      # seed 90, 20 000 варок на строку
player = sim_player.build_tables(volume)
week = sim_week.build_tables(player)
```

Формулы импортируются без построения этих таблиц. Случайному расчёту можно передать random.Random через аргумент rng. Готовые таблицы передаются обычными словарями; состояние потока хранится в rng_state. Статистика volume_stats не имеет скрытого кеша случайных результатов.

```python
import random
import sim_plan

rng = random.Random(20261008)
income = sim_plan.per_hour(8, rng=rng)
budget = sim_plan.week(8, 5, 4, 5, 22, income=income)
```

Старые неявные глобальные таблицы заменены build_tables. Тесты и сборщики проекта переведены на этот API. Каталог карточек запрашивается через prepare_cards, а построение и запись материалов разделены на build_materials и write_materials.
