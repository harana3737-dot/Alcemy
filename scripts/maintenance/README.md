## Справочник обслуживает Python и помощник

`scripts/rules_data.py` хранит цены трав, СЛ зелий и эликсиров, цены и параметры
чернил и катализаторов, бонусы мастерства, лаборатории, партии, лечение,
объёмы работы и справочные поля карточек. Старые имена модулей сохраняются.
JavaScript получает значения через маркеры шаблона при сборке помощника;
формат вставки сохраняет прежний HTML побайтово. Для партий и бонуса
мастерства выражения JavaScript строятся из общих данных.

Цена эликсира имеет СЛ зелья +2; разные значения здесь относятся к разным
классам предметов и не являются противоречием. Разные пределы и срезы
таблиц также сохраняют прежний диапазон поддерживаемых входов.

## Два различия сценариев оставлены вопросами игроку

Это различия допущений расчётов о будущем персонаже, а не новые правила.
Случайные числа и опубликованные результаты сохранены по обоим вариантам.

| Вопрос игроку | Что было в исходниках | Сохранённые варианты |
| --- | --- | --- |
| На мастерстве алхимии 3 расчёт роста должен предполагать бонус владения +2 или +3? Или оставить разные сценарии? | `sim_player.PROF[3] = 2`, `sim_week.prof(3) = 3`; уровень персонажа не определяется одним только мастерством алхимии | `PLAYER_PROF` и `WEEK_PROF` раздельно; выбор не сделан |
| На мастерстве 1–3 сравниваем инструменты без места (+0) или уже доступное рабочее место (+1)? Или оставить оба сценария? | `sim_player.LAB[1..3] = 0`, `sim_week.lab(1..3) = 1` | `PLAYER_LAB` и `WEEK_LAB` раздельно; выбор не сделан |

**Рекомендация Codex:** оставить явно названные разные сценарии; при сравнении
результатов задавать один и тот же уровень персонажа и место. Текущий лист
Талиса уже задаёт бонус проверки +4; этот перенос его не пересматривает.

## Уточнение игрока — 09.10.2026

**Статус:** решение игрока о рабочем месте; возможный рост уровня персонажа — предположение.

- Бонус рабочего места для выбранного сценария: **+1**. Это окончательное уточнение вместо первоначального ответа +0.
- К мастерству алхимии 3 персонаж **может** достичь 5 уровня; срок не подтверждён.
- На уровне персонажа 5 бонус владения +3; до этого — +2. Само мастерство алхимии 3 не повышает бонус владения.

Вопрос о рабочем месте закрыт для выбранного сценария. Для будущих сравнений
использовать +1 и явно указывать уровень персонажа. На мастерстве алхимии 3
пока показывать оба варианта бонуса владения: +2 и +3.

Таблица выше описывает исходные расхождения, найденные при рефакторинге.
Исторические расчёты `PLAYER_*` и `WEEK_*`, их снимок и протоколы не переписаны:
они доказывают сохранение результатов прежней задачи. Текущий лист персонажа
и общий бонус варки этим уточнением не пересчитываются.
