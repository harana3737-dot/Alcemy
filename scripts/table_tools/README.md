# Инструменты боя и ремёсел

Codex, 09.10.2026. Изменения интерфейса части А; правила и лист персонажа сохранены.

## Коротко

- Кузня начинает с пустого журнала. Пример включается явно и отличается от настоящей работы.
- Бой хранит ресурсы Талиса вместе с поясом; старые файлы получают новые поля без потери сумок.
- Две единицы Адепта доступны только для метамагии и не создают ячейки.
- «Перед волной» восстанавливает выбранные ресурсы по словам мастера для этого боя; расходники не возвращает.

**Как читать.** Для источников чисел — следующий раздел; команды проверки и ограничения — ниже.

## Откуда взяты числа

### Сочетания и незавершённые варки

Codex, 09.10.2026. Вкладка «Сочетания» проверяет план из сумки одного персонажа; переключатель открывает весь каталог. До пяти видов эликсиров, количество доз задаётся отдельно. Проверка учитывает текущую токсичность, действующий эффект под алхимической концентрацией и записанное заклинание с обычной концентрацией. Для Талиса заклинание берётся из панели «Бой», для остальных его можно ввести вручную.

Токсичность и алхимическая концентрация берутся из данных карточек, обычная — из поля `conc` для зарядов. Появляются предупреждения о превышении предела, замене концентрационного эффекта, одинаковых эффектах и нехватке доз. Два разных вида концентрации совместимы. Особые бонусы и варианты флакона проверяются по тексту карточки: план использует основную токсичность. Числовые модификаторы разных эффектов автоматически не складываются.

План хранится локально отдельно от игрового состояния. Выбор не расходует сумку, не меняет хиты и не прекращает эффекты. В резервную копию игрового состояния этот личный план не включён.

На вкладке «Варка» показаны незавершённые долгие варки с прогрессом, готовностью к завершающему броску и переходом в журнал. Испорченная варка остаётся помеченной до удаления. Скрытый список доступных рецептов больше не перестраивается при действиях в поясе; при возврате на «Варку» он обновляется.

Исходник — `../cards/table_combinations.js`, встраивается `helper.py`. Проверка — `test_table_combinations.cjs`; входит в `check_all.py --browser`. Мобильная проверка также открывает новую вкладку на 360–414 пикселях.

### Ресурсы боя

Хиты, уровень, классовые единицы, отдельный запас Адепта и стоимость создания
ячеек сборщик читает из «Талис — лист персонажа.md». При неполных или
неоднозначных данных сборка останавливается.

Максимумы ячеек в листе отсутствуют. Вопрос игроку: четыре ячейки I и три II
на 4 уровне без заранее созданной дополнительной ячейки, либо другие числа?
Рекомендация Codex — первое. **Игрок подтвердил I — 4, II — 3, 09.10.2026.**
Подтверждение хранится в `../cards/talis_resources.json`; изменение уровня
персонажа требует обновить его, а не молча продолжать со старым запасом.
Лист персонажа не редактировался. Других открытых вопросов по ресурсам нет.

При преобразовании ячейки расходуются только классовые единицы;
дополнительные ячейки могут превышать базовый запас. Возврат единиц
ограничен классовым максимумом; кнопка недоступна, если итог его превышает.
Для метамагии запасы тратятся отдельными кнопками: смешанный расход
записывается двумя действиями.

Урон вводится после сопротивлений. СЛ концентрации использует весь
полученный урон, включая часть, поглощённую временными хитами; половина
округляется вниз, как в существующей модели `vordt_engine.py`.
При нуле хитов концентрация прекращается. Спасброски от смерти,
спасброски концентрации и действия союзников интерфейс не разыгрывает.
Кнопка реакции лишь отмечает расход; ячейку на Щит следует потратить отдельно.
«Перед волной» не выполняет отдых, не сдвигает время и не возвращает зелья.

## Как проверить

Генерация выполняется в свежей временной копии без `.git`, затем готовый
«Помощник варки.html» переносится в ветку своего пункта.

```sh
python3 -B scripts/check_all.py --browser
```

Если Chromium установлен по другому пути:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium python3 -B scripts/check_all.py --browser
```

`test_table_combat.cjs` проверяет бой на 390 и 1280 пикселях, списание зелья,
волну, концентрацию, временные хиты, реакцию, преобразования, реальное
скачивание и восстановление файла, отказ на повреждённых ресурсах и старый
файл без новых полей. `test_combat_limits.py` проверяет чтение изменённых
чисел из листа и отказ при неопределённости. Общее состояние сохраняется
прежним механизмом `belt/state`; проверка здесь использует локальный профиль
и не меняет опубликованные данные игрока.

## Мобильный бой и ответы мастера

На ширине до 480 пикселей режим «Только бой» сворачивает описание и кнопки
сохранений за кнопкой «Сохранения и описание», поднимает бой над часами и
закрепляет вкладки. На ПК порядок блоков и вид шапки сохраняются.

В пульте общий счётчик и подписи групп показывают отмеченные ответы,
включая «Обсудить». Неотмеченные остаются принятыми по прежнему соглашению;
подпись объясняет это отдельно. `tally()` и текст отчёта для Claude сохранены.

## Сочетания и план варки — октябрь 2026

Вкладка **«Сочетания»** учитывает вариант токсичности, длительность и окно
заряда, «Чистый», двойной заряд и дефекты флакона. Бонусы привязки,
усиления и применения показываются рядом с эффектом. Для привязки
сохраняется граница правил 8.12: она повышает табличные значения,
а не собственную заклинательную СЛ. Продление времени не добавляет
использований ограниченного ресурса.

Флакон из сумки выбирается по пометке качества: недостаток такой позиции
считается отдельно от общего числа доз того же рецепта. Вручную изменённые
бонусы — сценарий, наличие таких бонусов в сумке не подтверждается.
Вариант выбирается явно; если его название записано в пометке, выбор
переносится из неё. Три пресета Codex: защита, разведка, урон и реакция.
Поиск и фильтры сокращают список для добавления, уже выбранный план сохраняют.

Вкладка **«План варки»** содержит:

- Прогноз до следующего мастерства. Текущий прогресс берётся из журнала;
  отдельное поле позволяет рассчитать сценарий. Модель освоенных зелий
  своего уровня учитывает независимые броски доз, натуральные 1 и 20,
  полную последнюю партию и пять стабильных применений катализатора.
  Стоимость — полная ценность расхода, без экономии трав за качество,
  ремонта, риска катализатора и выручки. Часы и недели — математическое
  ожидание при неизменном бонусе, не гарантированный срок.
- Подбор под бюджет **докупки**, время, материалы и нужду группы.
  Использует `supply()` и отмеченные известные рецепты, проверяет мастерство
  и оборудование. Неизвестная цена компонента не считается нулём.
  Категории определяются задачами карточек. Пять результатов — отдельные
  альтернативы на одну попытку, не совместный план расхода.
- Для эликсиров VI+ время оценивается по объёму работы: половинный прогресс,
  потеря к20, граница нуля и двухчасовые подходы. Простой исключён.
  Завершающий шанс показывается до модификатора меток и дефектов;
  указанное время остаётся средним. Для обычных зелий используются их
  собственные правила партий и времени, включая VI+.

Пресеты и порядок подбора — рекомендации Codex. Цена, сила эффектов,
известные рецепты и решения мастера автоматически не меняются.
Сценарии сохраняются локально отдельно от игровых ресурсов. Экспорт JSON
содержит оба плана; импорт проверяет их и поддерживает старые сохранения
без этого блока. Старый файл оставляет текущие локальные планы.

Исходники: `scripts/cards/table_combinations.js`, `table_planning.js`,
`table_tools.js` и `helper_tpl.html`. Сборщик `helper.py` получает таблицы
роста, СЛ зелий и стоимости катализаторов из `scripts/rules_data.py`.
Готовый документ — `Помощник варки.html`.

`test_table_planning.cjs` проверяет расчёт партий независимыми формулами,
долгую варку независимой симуляцией, бюджет, материалы, время, мастерство,
пресеты, варианты флаконов, перенос пометок, сохранение и восстановление
планов без расхода ресурсов. Мобильная проверка открывает новую вкладку
на ширинах 360–414 пикселей.

Проверка этой доработки: `check_all.py --slow --browser` — 162 теста Python,
184 карточки без ошибок и предупреждений, семь браузерных сценариев;
устаревших файлов нет. Все документы пересобраны во временной копии,
в задачу включён обновлённый `Помощник варки.html`.
