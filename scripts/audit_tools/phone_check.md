# Измерить помощник на своём телефоне

Codex, 10.10.2026. Локальная проверка; замер на физическом телефоне выполняет игрок.

**Как читать.** Открой готовый HTML проверки в браузере телефона, выбери резервную копию и запусти испытание. Итог — небольшой JSON с задержками. Проверка не меняет рабочую страницу или аккаунт.

1. В рабочем помощнике скачай резервную копию обычной кнопкой экспорта. Держи её у себя; загружать в сервис для измерения не нужно.
2. Открой «Проверка помощника на телефоне.html» в браузере, укажи модель телефона и браузер. Выбери резервную копию локальным выбором файла. Без неё проверка использует начальные сумки из проекта, а не твоё текущее сохранение.
3. Нажми «Запустить проверку». Страница сама прокрутит испытательную копию в видимую область. Не переключай приложение, вкладку и ориентацию экрана до окончания. Выполняются добавление предмета, отмена, открытие журнала, изменение состояния при открытом журнале и ход в бою.
4. Скачай `alcemy-phone-results.json`. В нём — 15 измерений на действие после трёх разогревов, сведения браузера, модель телефона, число записей и SHA-256 испытанной сборки. Имена, предметы, деньги и текст журнала в результат не входят.
5. Отдельно в рабочем помощнике проверь открытие всех вкладок, клавиатуру при вводе, экспорт, отмену и восстановление после перезагрузки. Эта ручная проверка охватывает постоянное сохранение и особенности браузера, которые испытательная копия не измеряет.

Испытательная копия работает в изолированном iframe с хранилищем в памяти и запретом сетевых запросов. Она измеряет обработчики, построение DOM и время до двух следующих кадров. Облачная синхронизация и постоянная запись в хранилище в задержки не включены. Это ограничение нужно учитывать при сравнении с рабочей страницей. Выборка 15 невелика: 95-й процентиль равен максимальному времени из этих 15 измерений.

Если приложение просмотра файлов не исполняет JavaScript, открой файл именно в браузере. Для локального HTTP-размещения на компьютере положи только этот HTML в отдельную папку, запусти в ней `python3 -m http.server 8770 --bind 0.0.0.0` и открой на телефоне в той же домашней сети `http://<адрес-компьютера>:8770/`. По окончании останови сервер. Не раздавай целиком папку проекта.

## Собрать новую проверку

Сначала собери помощник в временной копии без `.git`, затем:

```sh
python3 -B scripts/audit_tools/build_mobile_check.py --root /tmp/repo --output /tmp/phone-check.html
```

Готовый файл содержит испытательную копию, поэтому не требует соседних файлов. Проверка `scripts/cards/test_mobile_probe.cjs` испытала загрузку сохранения, все пять действий, отмену, скачивание отчёта и отсутствие приватных строк в нём при ширине 360 px. Это автоматическая эмуляция; результат физического телефона ещё не получен.
