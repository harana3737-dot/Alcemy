# Выполнены пункты сопровождения после аудита

Codex, 10.10.2026. Исходники для интеграции в общей ветке; правила и цены сохранены.

**Как читать.** Ниже — результат каждого пункта и что пересобрать. Инструкции для телефона — [phone_check.md](phone_check.md), сценарии рынка — [market_guidance.md](market_guidance.md).

## CI проверяет исходники и новую сборку

Существующий GitHub Actions расширен: проверяются проекции реестра, списки карточек, синтаксис JavaScript свежих страниц, отсутствие маркеров шаблона, размеры помощника и пульта. Добавлена сверка точного расчёта с Монте-Карло на 400 сочетаниях, по 10 000 катализаторов. Версия Playwright закреплена в lock-файле.

Режим `--sources` собирает документы в временной копии и сообщает, что пересобрать после интеграции. Он не требует коммитить промежуточные готовые документы в ветку исходников. Неудачный тест или изменение checkout остаётся ошибкой. Без этого флага проверка по-прежнему требует актуальности готового комплекта. Пределы размера обеих страниц — 600 КиБ; это контроль роста, не оценка задержки.

## Классификация карточек хранится в данных

Добавлены `soft`, `stacks_8_9` (подпадает под ограничение одного эффекта), `concentration` и исключения вариантов `soft_variants`. Текстовые `a89` и `conc` оставлены как совместимый вывод. Помощник использует булевы признаки. Проверочная сверка подтвердила идентичность всех прежних полей, включая цены, уровни, номера карточек и убранные заряды-основы.

Списки мягких/немягких эликсиров в 8.7 и подпадающих/неподпадающих под 8.9 генерируются из этих признаков. Механика и альтернативы сохранены. Левитация не мягкая и вне 8.9, Паук мягкий, Полёт под 8.9; отдельные правила вариантов Телосложения и «Задержать» учтены в данных. Пограничная пометка Сопротивления сохранена.

## Реестр не переоткрывает решения

`questions.csv` содержит 46 действующих В-ID, 58 существующих записей Ж-ID и 31 отметку утерянных вопросов 9–39. Источник старых вопросов отсутствует и в файлах, и в доступной истории Git. Текст не восстанавливался предположениями. В очередь не добавлены новые вопросы, статусы не менялись.

`STATUS.md` объясняет статусы и отсутствие индивидуальных дат. Проверка ловит несуществующие ID, ошибочные диапазоны и ссылки на закрытый В-ID как на нерешённый вопрос; ссылки на принятое решение и историю допустимы.

## Проверка телефона подготовлена для игрока

Автономный HTML загружает рабочую резервную копию локально в изолированную испытательную страницу. Пять действий измеряются после разогрева, отдельно проверяется отмена. Скачиваемый JSON не содержит людей, предметов и журнала сохранения; рабочее хранилище не меняется. Автоматический тест проверил этот путь при ширине 360 px.

Физический телефон недоступен в среде. По ответу игрока готовый файл передаётся для самостоятельного запуска. До получения результата нельзя объявлять физический замер выполненным. В испытании не измеряется постоянная запись или облачная синхронизация; ручная проверка рабочего помощника описана отдельно.

## Сценарии баланса и скилл готовы

`balance_scenarios.py` исследует денежный поток при дневной ёмкости рынка и сравнивает исторический и оптимальный выбор перебросов. Непроданный склад не оценивается и не реализуется позднее; производство выполняется по заданному плану. Эти допущения записаны рядом с числами. Безлимитный исторический расчёт совпадает с прежней моделью; изменения игровых правил не вносились.

`.claude/skills/balance-auditor/SKILL.md` задаёт пять направлений аудита, источники, воспроизведение и формат замечаний. Вызов `/balance-auditor` явный; автоматический вызов отключён. Скилл не рассылает отчёты и не меняет игровые решения.

Скомпилированы 19 JavaScript-источников; в свежих страницах нет незаменённых маркеров. Проверка карточек: 184, 0 ошибок. Размер свежей сборки: помощник 545 970 байт, пульт 548 837 байт, оба ниже предела 614 400. Устаревшие готовые файлы перечислены проверкой для интегратора. Результат GitHub Actions после push в этом отчёте не заявляется — выполнена локальная эквивалентная проверка.

## После объединения пересобрать комплект

Полный текст правил обновлён только в блоках классификации и пояснениях сохранённых альтернатив. Пересобрать правила v0.3 HTML, правила за столом MD/HTML, помощник, пульт мастера и книгу игрока с архивами. Карточки и их HTML проверочно собрать из новых исходников. CSV и STATUS уже включены в пакет; при новых изменениях очереди или журнала пересобрать их.

Общая проверка из исходников:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium python3 -B scripts/check_all.py --sources --slow --browser
python3 -B scripts/scenario_engine.py --grid --runs 10000
```

После сборки итогового комплекта повторить команду без `--sources`. Публикация страниц остаётся отдельным шагом.
