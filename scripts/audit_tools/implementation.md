# Выполнен первый пакет правок по аудиту

Codex, 10.10.2026. Технические изменения для интеграции; игровые правила и цены сохранены.

## Что изменилось

- Импорт сохранений проверяет вложенность без рекурсии. При глубине больше 32 выдаётся понятная ошибка до применения данных; опасные ключи по-прежнему отклоняются.
- Экономические модели получают вид и уровень предмета явно. Стоимость материалов больше не используется для определения зелья. Возможность 9.9 → 10.10 передаётся параметром и по умолчанию сохраняет прежнее поведение.
- Справочные таблицы перенесены в `rules.json`. Python и сборщик JavaScript читают их через совместимый `rules_data.py`. Различия сценариев `player` и `week` сохранены; цены катализаторов и основные таблицы лабораторий больше не поддерживаются отдельными копиями в затронутых потребителях.
- Скрипт сверяет выбранные числа ядра правил, шпаргалки и экономики. Отсутствие таблицы или строки — ошибка, а не пропуск. Он включён в общую проверку сборки вместе с проверкой валидатора без браузера.

**Как читать.** Порядок изменения данных, границы сверки и команды — в [инструкции](README.md).

## Проверки пройдены

- 182 Python-теста: 175 в `scripts`, 7 в `scripts/cards`, во временной копии.
- Полная проверочная сборка `check_all.py --slow --browser` с Chromium `/usr/bin/chromium`: без ошибок и устаревших файлов в предварительно пересобранной временной копии.
- Все семь браузерных сценариев: ремёсла и пульт, бой, сочетания, мобильный интерфейс, планирование, инструменты помощника и книга игрока. Импорт глубокой структуры отклоняется через интерфейс, не меняет состояние и не открывает подтверждение восстановления. Обычное сохранение имеет глубину меньше 10.
- Валидатор без браузера: обычное сохранение, граница 32, структура глубиной 15 000, опасные ключи.
- Проверка документов: намеренно изменённые цена, СЛ, размер партии, лестница риска и удалённая таблица обнаружены; посторонняя альтернатива игнорируется. Порядок ключей JSON не меняет результаты.
- Таблицы CLI `sim.py`, контрольные случайные расчёты с прежним начальным состоянием генератора и оба Markdown-отчёта экономики совпали с исходной версией. Исходная версия отдельно пересобрана из Git-снимка до правок.
- Последнее изменение порядка чтения числовых ключей не меняет собранный HTML помощника; все Python-тесты повторно прошли.
- `git diff --check`: без ошибок.

Генерация выполнялась вне checkout, в копиях без `.git`. Готовые игровые документы в ветке задачи не перезаписаны.

## Что пересобрать после интеграции

`Помощник варки.html` зависит от изменённых шаблона и JavaScript. Его нужно собрать через `python3 -B scripts/cards/helper.py` из объединённых исходников, проверить и затем опубликовать отдельным шагом.

Пересчёт экономики и карточек проверен; прежние значения сохраняются. Отчёты и готовые HTML других документов не требуют содержательных изменений в этом пакете.

Новые лимиты рынка, изменения СЛ и цен, пересмотр токсичности, оптимизация интерфейса и отдельный движок сценарных исследований остаются за пределами выполненного пакета.
