# Прогоны алхимии и заклинаний

Расчёт Codex по закреплённому SRD 2014 и текущим карточкам Alcemy. Основной документ: `Алхимия и магия — проверка на бестиарии.md`, готовый HTML рядом с ним. Правила и цены расчёт не изменяет.

## Запуск

Из корня репозитория:

```bash
python3 -B -m unittest discover -s scripts -p test_alchemy_bestiary.py
python3 -B scripts/alchemy_bestiary_report.py --write
python3 -B scripts/alchemy_bestiary_report.py --check
python3 -B scripts/master_html.py 'Алхимия и магия — проверка на бестиарии'
```

Генерацию выполнять в свежей временной копии без `.git`, затем переносить проверенные результаты в checkout согласно AGENTS.md. Дополнительных пакетов не требуется.

## CSV

`results.csv` содержит одну строку на уровень, противника, роль, сценарий и метрику. `mastery_min` — минимальный уровень предмета, независимо от уровня персонажа. Пустая цена означает, что стоимость в этой строке не рассчитывается; это не бесплатный рецепт. `cost_gp` — цена исходной карточки, без умножения стоимости на коэффициент качества. Сильный и мощный контрольные яды меняют только Сл на +1/+2.

- `damage_3_rounds`: урон за три хода указанного сценария; у обычного яда без оружия и дополнительных триггеров.
- `damage_on_placement`: одна цель, склянка размещена правильно.
- `damage_precise_only`: урон склянки × вероятность точного броска; рассеянные броски оценены нулём.
- `delivery_probability`: одно попадание рапирой и первоначальный эффект контрольного яда.
- `active_target_turns`: ожидаемое число ходов с эффектом на указанном горизонте, не число потерянных действий.
- `damage_next_cast`: только следующее заклинание после яда; первая атака и потраченное действие исключены.
- `damage_weapon_turn`: один устойчивый оружейный ход после подготовки.
- `damage_3_contacts`: три условных контакта с длительным заклинанием.
- `initial_damage` / `additional_damage`: отдельные части психического урона, не общий урон боя.
- `trigger_probability`: вероятность хотя бы одного высокого триггера обычного яда, без моделирования его последствий.
- `exhaustion_death_10_contacts`: смерть от истощения при десяти гарантированных контактах, не вероятность победы.

`with_lr` показывает сценарий, где противник тратит доступное легендарное сопротивление на первые провалы. Пустое поле означает, что отдельный прогон с ЛС для данной метрики не нужен. `baseline` имеет ту же метрику и горизонт, но без добавленной алхимии, кроме явно описанного сравнения с Ускорением и священным маслом.

## Границы

Характеристики будущих персонажей и заклинания — сценарные допущения; мастерство рецептов и известные заклинания не меняются. Все ограничения, включая размер клетки, языки внушения и трактовку иммунитета ракшаса, описаны в основном отчёте. Источник SRD и лицензия: `../bestiary/README.md`, `../bestiary/UPSTREAM_LICENSE.md`.

Алгоритмы используют точное перечисление кубиков и вероятностные состояния. Случайных бросков нет; повторный запуск даёт те же файлы. Тесты проверяют также сохранение суммарной вероятности для всех 334 существ.
