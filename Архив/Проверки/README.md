# Расчётные источники и исторические срезы

Завершённые отчёты об аудитах убраны из рабочего дерева. [Одна актуальная сводка](../../История%20проверок%20—%20оглавление.md) содержит исправления, оставшиеся задачи и порядок дальнейшей работы; подробности прошлых проверок доступны в истории Git.

Здесь остаются источники, которые читают сборщики, книга или реестр вопросов, а также исторические планы и срезы кампании. Это не склад повторяющихся технических отчётов. Исходные расчёты, вопросы и состояние прошлых сессий не удаляются вместе с аудитами.
