# Архив проверок

Здесь находятся десять датированных аудитов, оценок и отчётов об исправлениях, а также пять их HTML-версий. Они сохраняют историю работы; состояние проекта ищи в актуальных документах.

Маршрут к действующим материалам — [История проверок — оглавление](../../История%20проверок%20—%20оглавление.md). Отчёты не удалены. При переносе обновлены относительные ссылки; выводы, даты, числа и статусы сохранены.

Для пересборки отдельного HTML из корня проекта используй прежнее имя, например:

```bash
python3 -B scripts/master_html.py "Проверка экономики — 2026-10-08"
```

Сборщик читает Markdown из этой папки и пишет HTML рядом. Проверочную генерацию выполняй в свежей временной копии без `.git`.
