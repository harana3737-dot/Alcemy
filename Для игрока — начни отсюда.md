# Для игрока — начни отсюда

**Перед игрой — «Талис — что делать сейчас»:** одна страница с конкретными приёмами на текущий уровень. К бою с Вордтом — «Бой с Вордтом — план».

Открой **«Для игрока — книга алхимии.html»**. Это единый комплект: понятные объяснения, примеры, альтернативы, поиск и библиотека исходных материалов. Работает без интернета; опубликованный Помощник варки отдельно хранит игровой журнал.

Первое чтение: главы 1–6. Перед боем: 10–14. Для исследований и развития: 15–19. Если непонятно слово — глава 22 или Глоссарий. В библиотеке на виду восемь практических справок; четырнадцать подробных источников собраны в блоке «Дополнительные документы». Поиск и ссылки находят оба блока.

## Два комплекта по запросу

Архивов в репозитории нет, и в Git они не хранятся. Для получения обоих комплектов выполнить в свежей временной копии без `.git`: `python3 -B scripts/player_book.py`. Готовая книга HTML остаётся в проекте.

- **«Материалы игрока — читаемый комплект.zip»** — только книга HTML и этот указатель. Для чтения больше файлов не нужно: все 22 источника встроены в книгу.
- **«Материалы игрока — исходники книги.zip»** — Markdown книги, её 22 источника, указатель, сборщик, шаблон и браузерная проверка. Нужен для редактирования и восстановления книги. После распаковки в пустую папку команда python3 -B scripts/player_book.py пересобирает книгу и оба архива; внешние библиотеки для сборки не нужны. Это исходники книги, а полный проект остаётся в репозитории.

Данные живого журнала не входят в эти архивы; для них используется отдельная резервная копия Помощника варки.

Числа — срез на 07.10.2026, не автоматическая синхронизация с журналом. Тактические советы не меняют правил. Цены моделей и старые сценарии не означают, что нужно покупать все расходники или что все рецепты уже открыты.

Для обновления комплекта: в свежей временной копии без .git выполнить python3 -B scripts/player_book.py. Сборка берёт объяснения из «Для игрока — книга алхимии.md», оформление из scripts/player_book_tpl.html, исходники библиотеки перечислены в scripts/player_book.py. Цены, правила и сохранения игрока не изменяет.

Проверка актуальности: `python3 -B scripts/player_book.py --check`. Она пересобирает книгу из текущих 22 источников и шаблона во временную папку, завершается с ошибкой при отсутствующем или устаревшем HTML в проекте. Архивы также собираются и проверяются, но не сравниваются с репозиторием; проект не изменяется.

Проверка чтения после сборки: node scripts/test_player_book.cjs (Playwright и Chromium). Она проверяет поиск в закрытых примерах, внутренние ссылки, темы, шрифт, мобильное представление, печать и чтение без сети/JavaScript. При изменении источников библиотеки пересобрать книгу и оба архива; отдельный отчёт «Группа — баффы и расходники.html» обновляется через scripts/master_html.py.

## Какие отдельные файлы можно убрать из папки для чтения

| Файлы | Почему их не нужно держать под рукой |
| --- | --- |
| Отдельные HTML обзора, баффов, экономики и бонусов | Их содержание уже встроено в книгу; отдельные версии нужны только для отправки одного документа |
| Аудит v0.3 — 2026-10-05, аудит 06.10 и проверка 07.10 | История технических проверок, не инструкции для очередной вылазки |
| Проверка сочетаний, игровые сценарии, проверка на бестиарии, разбор исключений | Проверки модели и варианты обсуждения; доступны в дополнительной библиотеке |
| Экономика для мастера | Представление той же расчётной модели для другого читателя; игроку хватает своих глав и симуляции |

В проекте эти документы сохраняются по назначению. **Полную v0.3, ядро, Журнал решений, Очередь вопросов, лист и заметки удалять из проекта нельзя без переделки зависимостей:** сборщики используют их, а книга не заменяет редактируемые исходники. Рецепты и цены редактируются в своих источниках, затем результаты пересобираются.

Для развития чародея — «Заклинания Талиса — проверка на бестиарии»: независимый воспроизводимый расчёт Codex и рекомендации по уровням с примерами, встроенные в библиотеку книги. Полные данные и генератор — scripts/bestiary/ и scripts/bestiary_report.py в репозитории; прочитанные внешние источники и ограничения перечислены в разборе.
