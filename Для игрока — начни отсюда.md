# Для игрока — начни отсюда

**Перед игрой — «Талис — что делать сейчас»:** одна страница с конкретными приёмами на текущий уровень. К бою с Вордтом — «Бой с Вордтом — план».

**Как читать.** Перед игрой открой «Талис — что делать сейчас», для общего чтения — книгу; архивы нужны для передачи и редактирования.

Открой **«Для игрока — книга алхимии.html»**. Это единый комплект: понятные объяснения, примеры, альтернативы, поиск и библиотека исходных материалов. Работает без интернета; опубликованный Помощник варки отдельно хранит игровой журнал.

Первое чтение: главы 1–6. Перед боем: 10–14. Для исследований и развития: 15–19. Если непонятно слово — глава 22 или Глоссарий. В библиотеке на виду восемь практических справок; четырнадцать подробных источников собраны в блоке «Дополнительные документы». Поиск и ссылки находят оба блока.

Числа — срез на 07.10.2026, не автоматическая синхронизация с журналом. Тактические советы не меняют правил. Цены моделей и старые сценарии не означают, что нужно покупать все расходники или что все рецепты уже открыты.


Пять отдельных документов рядом с книгой (в книгу не встроены):

- [Первая варка — по шагам](Первая%20варка%20—%20по%20шагам.md): проведи одну попытку лечения 1.1 с текущими запасами.
- [История проверок — оглавление](История%20проверок%20—%20оглавление.md): найди действующий документ вместо старого аудита.
- [Аудит — вопросы для решения](Аудит%20—%20вопросы%20для%20решения.md): принятые уточнения потолка уровня, половинной цены и примерной ставки продажи; расчёты их последствий.
- [Аудит — проверка оставшихся гипотез](Аудит%20—%20проверка%20оставшихся%20гипотез.md): результаты проверок ядов, лечения, сочетаний, долгой варки и таблиц; восстановление вопросов старой сводки.
- [Аудит — код, репозиторий и читаемость](Аудит%20—%20код,%20репозиторий%20и%20читаемость.md): найденные ошибки, исправления, размеры данных, проверки и интернет-источники.

В проекте эти документы сохраняются по назначению. **Полную v0.3, ядро, Журнал решений, Очередь вопросов, лист и заметки удалять из проекта нельзя без переделки зависимостей:** сборщики используют их, а книга не заменяет редактируемые исходники. Рецепты и цены редактируются в своих источниках, затем результаты пересобираются.

Для развития чародея — «Заклинания Талиса — проверка на бестиарии»: независимый воспроизводимый расчёт Codex и рекомендации по уровням с примерами, встроенные в библиотеку книги. Полные данные и генератор — scripts/bestiary/ и scripts/bestiary_report.py в репозитории; прочитанные внешние источники и ограничения перечислены в разборе.

## Как получить два комплекта

Сборщик создаёт оба архива в свежей временной копии без `.git`. Команда: `python3 -B scripts/player_book.py`. Архивы в Git не хранятся; готовая книга HTML остаётся в проекте.

- **«Материалы игрока — читаемый комплект.zip»** — только книга HTML и этот указатель. Для чтения больше файлов не нужно: все 22 источника встроены в книгу.
- **«Материалы игрока — исходники книги.zip»** — Markdown книги, её 22 источника, указатель, сборщик, шаблон и браузерная проверка. Нужен для редактирования и восстановления книги. После распаковки в пустую папку команда `python3 -B scripts/player_book.py` пересобирает книгу и оба архива; внешние библиотеки для сборки не нужны. Полный проект остаётся в репозитории.

Данные живого журнала не входят в эти архивы; для них используется отдельная резервная копия Помощника варки.

Источники сборки: объяснения — «Для игрока — книга алхимии.md», оформление — `scripts/player_book_tpl.html`, список документов библиотеки — `scripts/player_book.py`. Сборка сохраняет цены, правила и данные игрока.

Проверка актуальности: `python3 -B scripts/player_book.py --check`. Книга пересобирается из текущих 22 источников и шаблона во временную папку. Отсутствующий или устаревший HTML даёт ошибку. Архивы тоже собираются и проверяются; с репозиторием сравнивается только HTML. Файлы проекта при проверке сохраняются.

Проверка чтения после сборки: `node scripts/test_player_book.cjs` (Playwright и Chromium). Проверяются поиск в закрытых примерах, внутренние ссылки, темы, шрифт, мобильное представление, печать и чтение без сети и JavaScript. После правки источников пересобери книгу и оба архива. Отдельный отчёт «Группа — баффы и расходники.html» обновляется через `scripts/master_html.py`.
