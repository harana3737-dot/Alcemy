# Для игрока — начни отсюда

Открой **«Для игрока — книга алхимии.html»**. Это единый комплект: понятные объяснения, примеры, альтернативы, поиск и библиотека исходных материалов. Работает без интернета; опубликованный Помощник варки отдельно хранит игровой журнал.

Первое чтение: главы 1–6. Перед боем: 10–14. Для исследований и развития: 15–19. Если непонятно слово — глава 22 или Глоссарий. Исходники, включённые в книгу, собраны в библиотеке в её конце; файлы отдельно находятся в архиве «Материалы игрока — читаемый комплект.zip».

Числа — срез на 07.10.2026, не автоматическая синхронизация с журналом. Тактические советы не меняют правил. Цены моделей и старые сценарии не означают, что нужно покупать все расходники или что все рецепты уже открыты.

Для обновления комплекта: в свежей временной копии без .git выполнить python3 -B scripts/player_book.py. Сборка берёт объяснения из «Для игрока — книга алхимии.md», оформление из scripts/player_book_tpl.html, исходники библиотеки перечислены в scripts/player_book.py. Цены, правила и сохранения игрока не изменяет.

Проверка чтения после сборки: node scripts/test_player_book.cjs (Playwright и Chromium). Она проверяет поиск в закрытых примерах, внутренние ссылки, темы, шрифт, мобильное представление, печать и чтение без сети/JavaScript. При изменении источников библиотеки пересобрать книгу и архив; отдельный отчёт «Группа — баффы и расходники.html» обновляется через scripts/master_html.py.
