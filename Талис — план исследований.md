**Первая потребность — два набора чернил II Лаэлю.** Чернила уже освоены: повторять исследование 30/100 не нужно. После них игрок выбирает метку или исследования; ниже сохранён вариант с лечением 2.2. Эликсиры дальше — Разум ради Бдительного отдыха, затем Тело ради Малого восстановления II и Щита веры I; это рекомендация, не назначенная очередь. Одной пробы рецепта 2.2 может не хватить.

| Следующие 2 часа | Второй набор II или повтор неудачной первой варки | Сколько наборов действительно изготовлено и хватает ли сырья |
| Оставшиеся до 6 часов | После двух готовых наборов: разбор образца 2.2 и до трёх двухчасовых проб | После каждой пробы — отметки, время, материалы и последствия единицы. Остановиться, когда рецепт открыт |
| Если 2.2 открыт раньше | Первую партию 2.2 делать только при оставшемся двухчасовом блоке и отдельных материалах | Открытие рецепта не добавляет готовые зелья в сумку |

Чернила варятся по одному набору за двухчасовую попытку, не партией из двух. На мастерстве 2 катализатор для II не требуется. СЛ 12: бонус +5 на рабочем месте; лабораторию для чернил сейчас не учитываем. Консультация Лаэля даёт +1 только при выполнении условий §10.5, в базовом плане её нет. Качество чернил фиксируется отдельно; нестабильный набор с −2 к Начертанию не записывать как обычный.

Если на каждый результат ниже СЛ доступен один переброс Волшебным указанием, шанс стабильного набора — 91% при +5. Вероятность двух стабильных наборов за первые две попытки — 82,81%. Это условные шансы без помех и дополнительных бонусов, не обещание двух флаконов. Переброс не получает второй переброс; максимум расходов в двух таких попытках — две единицы, и каждый расход записывается по факту.

Два обычных стабильных набора II дают одну практику мастерства по §3.2: после такой пары рост станет 5/15, сейчас остаётся 4/15. Натуральная 20 засчитывается отдельно по §3.2; фактический рост записывается по исходам варки. За один только план практика не начисляется.

## Почему 2.2 не обещается за одну пробу

Разобранный образец расходуется целиком и даёт одну отметку. Для рецепта нужно три: остаются две. Проба расходует половину лечебной травы II, то есть около 0,25 зм; образец даёт подсказку +2. СЛ 10, бонус пробы +7 на рабочем месте.

| Итог первой пробы | Что будет |
| --- | --- |
| Обычный успех | Ещё одна отметка: всего 2/3, нужна следующая проба |
| Успех на 5+ | Ещё две: рецепт открыт |
| Натуральная 20 | Три отметки за пробу: рецепт открыт |
| Провал | Завершение не гарантировано; при единице последствия выбирает мастер |

С одним перебросом именно провала шанс открыть рецепт первой пробой — 71,5% на рабочем месте. Успешную проверку без превышения на 5 ради этой оценки не перебрасываем. Поэтому после чернил оставлен запас до трёх проб; три тоже не являются безусловной гарантией при любых бросках. Повторно покупать и разбирать уже использованный образец для каждой пробы не нужно: подсказка сохраняется.

## Практика за открытие и путь к мастерству 3

По уточнению игрока (Ж-146) за завершённое открытие рецепта или ступени формулы пока засчитываем +1 практику. Это не награда за каждую пробу и не за одну только разборку флакона. Прошлые открытия уже учтены; текущий рост остаётся 4/15.

Ниже — пример сочетания целей игрока: чернила III, лечение 3.3 и Бдительный отдых. Порядок ещё выбирает игрок; таблица не означает, что работы состоялись.

| Будущая работа | Рост после выполнения |
| --- | --- |
| Текущий подтверждённый прогресс | 4/15 |
| Два обычных стабильных набора чернил II Лаэлю | 5/15 |
| Полностью открыть рецепт 2.2 | 6/15 |
| Полностью открыть обычную формулу Разума через Бдительный отдых | 7/15 |
| Первая обычная успешная варка Бдительного отдыха II | 8/15 |
| Ещё семь обычных успешных зелий 2.2 | 15/15 — мастерство 3 |

По выбору игрока готовим четыре полные партии: 2 + 2 + 2 + 2, восемь доз за четыре двухчасовых подхода, 8 часов. Для повышения нужны семь обычных успешных доз; при восьми успешных варках одно зелье будет сверх необходимого для роста. Последняя партия тоже объявляется из двух доз до начала работы. Это на 1 зм сырья больше семидозового варианта до экономии трав, время то же. Четыре подхода укладываются в разрешённую ночь под Бдительным отдыхом (не чаще раза в неделю). Лишняя практика за 2.2 не объявляется вкладом в переход 3 → 4: для него нужны изделия III уровня. Криты меняют число практик, провалы требуют добора; единицы на указание тратятся из фактического остатка, отдых восстанавливает ресурсы только после завершения ночи.

Для Разума на рабочем месте: +7 с подсказкой от эссенции II против СЛ 12; проба 2 часа и 5,75 зм сырья. Первая варка Бдительного отдыха: +5 против СЛ 14 (непривычный вариант), 2 часа и 1,5 зм сырья. Лаборатория здесь не учитывается. Исследование и приготовление эликсира требуют времени до первой такой ночи.

Мастерство 3 открывает обычную варку чернил III по уже известному рецепту, но нужны готовый катализатор I и сырьё. Для лечения 3.3 нужен отдельный рецепт по имеющемуся образцу; само повышение его не открывает. Бонус мастерства алхимика при переходе 2 → 3 не увеличивается.

## Метка и последующие исследования

На этап II требуется базовый комплект за 100 зм до уточнения зачёта серебрянки. После двух попыток чернил за 81 зм остаётся 27,18 зм; после всего указанного набора покупок — 21,68 зм. Поэтому оплату этапа II в этот план не включаем. Если мастер подтвердит уже имеющиеся материалы или другую доплату, пересчитаем конкретную операцию; сырой катализатор серебрянку не заменяет.

После заказа Лаэлю игрок выбирает между 2.2, формулами Тела, Разума, Движения и меткой с доступным снабжением. Ранее предложенный Codex порядок исследований не является обязательной очередью игрока. Формулы пока не открыты; предполагаемые будущие покупки и доход от продаж в текущий кошелёк не включаются.
